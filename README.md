# 🚂 Train Builder / Constructor de trenes / Constructeur de trains

A wooden-train construction game for young children, in a single offline HTML file.
Build track, ramps, spirals, switches, streets and monuments, then press ▶️ and watch the trains run.

- **Adventure:** 27 levels across Europe and South America.
- **Free play:** every piece, train, car and monument, plus ready-made city projects.
- **Tutorial:** step by step, read aloud.
- **Languages:** Español, English, Français (flags on the home screen).

Marketing page: https://train.fspal.com (`index.html`, assets in `site/`). Play the web game at https://train.fspal.com/racing/ (the old v1.0 build is in `play/`), or open its `index.html` in any browser. Progress is saved in the browser.
